# Martial Peak Landing Page

A fantasy-themed landing page inspired by the Martial Peak web novel. I like reading novels and wanted to try my hand at creating a landing page for the novel.
This project was created as a web development practice project to improve my HTML and CSS skills.

About the Project

This landing page introduces the Martial Peak novel and presents information about the story in a simple, visually appealing layout.

Features

- Hero section
- Novel introduction
- About the story
- Responsive layout
- Fantasy-themed design
- Navigation bar

Technologies Used

- HTML5
- CSS

Purpose

This project was built to practice:

- Structuring webpages with HTML
- Styling webpages with CSS
- Creating navigation sections
- Designing a clean landing page
- Improving responsive web design skills

Future Improvements

- Add more sections
- Improve mobile responsiveness
- Add animations and interactive elements
